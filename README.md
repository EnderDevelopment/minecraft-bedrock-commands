# CommandCraft

CommandCraft is a Minecraft plugin designed to enhance the command block system in Minecraft Bedrock Edition. It provides a set of custom commands that can be used to create complex and interactive gameplay experiences. The plugin is built with Java and utilizes the Bukkit API to interact with the Minecraft server.

## Install

1. Download the CommandCraft plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Once the server is running with the CommandCraft plugin, you can use the custom commands in your command block systems.
2. For example, to greet a player, use the `/ciao` command in a command block.
